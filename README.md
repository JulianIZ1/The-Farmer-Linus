# The Farmer Linus

## About this Mod
In Stardew Valley, Linus lives in a tent on the mountain (right in Robins backyard). This mod rewrites that story: starting off isolated, Linus is guided step by step out of hermit life and into a new one — with your help — as a farmer building roots in Cindersap Forest.

The goal of this mod is a narrative driven tranformation:
- New Locations
- New Dialouge
- New Events

And eventually, A new Linus that learns how to farm, builds his own little piece of property, and reconnects with the poeple of Pelican Town.

(Note: Mod is still being actively developed)

## Requirements
- SMAPI (latest version)
- Content Patcher

## Installation
1. Install SMAPI if you haven't already.
2. Install Content Patcher.
3. Download the latest release of this mod from the Releases page.
4. Extract the mod folder into your Stardew Valley/Mods directory.
5. Launch the game through SMAPI.
