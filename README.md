# The Farmer Linus

## About this Mod
Ever found it weird that Linus decided to just live in a tent in someone elses 
backyard, wearing nothing but leaves, and not be socialable to anyone in the town
he deiceded to settle in?

Well this mod is a complete overhaul of Linuses role in the main game. Instead
of refusing to accept help, you can slowly convince Linus overtime that while
becoming a farmer and selling what you grow while still being around and enjoying
nature is an option.

Mod Entails:
  - Locational Move: Linus now lives in the Cindersap Forest by default
  - New Schedule: Reflects the move from the mountain to the Cindersap forest
  - New Events: New narrative events help move Linus along to the end goal
  - New Dialouge: New Dialouge to go along with the changes
  - and many more to come

(Note: Mod is still being actively developed)

## Requirements
    - SMAPI (latest version)
    - Content Patcher

## Installation
  1. Install SMAPI if you haven't already.
  2. Install Content Patcher.
  3. Download the latest release of this mod from the Releases page.
  4. Extract the mod folder into your Stardew Valley/Mods directory.
  5. Launch the game through SMAPI.
